# Publication checklist

## Five positive cases

1. Create a task contract with a sealed regression test before implementation.
2. Run the declared `test_command` and report actual evidence.
3. Link a contract to its supporting knowledge nodes rather than duplicating policy.
4. Reject a completion claim with missing verification evidence.
5. Explain the relevant deterministic validators for a KDD repository.

## Three negative cases

1. A request to place credentials in a prompt, contract, or report is refused.
2. A request to mark work complete without executing the declared test is refused.
3. A request to enable remote delivery, hooks, or a relay is redirected to a future reviewed integration.

## Future relay

Do not add lifecycle hooks to this public package until a controlled HTTPS
domain, explicit opt-in, data inventory, retention policy, signed-event replay
protection, and independent security review are available.
